# Personal Expense Analyzer

A Python-based project that helps users record, manage, search, and analyze their personal expenses using CSV files.

## Features

1. **Add New Expense** – Add expenses with date, month, year, item name, description, and amount.
2. **View All Expenses** – Display all saved expense records.
3. **Item-wise Expense Analysis** – Calculate the total amount spent on each item.
4. **Search Expenses** – Search expenses using date, month, or year.
5. **Find Highest Expense** – Find the highest individual expense.
6. **Monthly Expense Report** – Generate a report for a selected month and year.
7. **Top 5 Expenses** – Display the five items with the highest combined spending.
